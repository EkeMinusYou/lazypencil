# GLSL fills and effects

Read an existing shader asset before editing it. Create new source with put_asset using kind: shader, then update the fill or effect URL through an atomic editing batch. Source uses WebGL 1.0 fragment GLSL, usually with an explicit precision declaration. It is compiled by software WebGL in a dedicated Chromium process and composited by Skia.

A block comment containing the exact directive @resolution associates a vec2 uniform with the raster's pixel dimensions. @time associates a float with the explicit render time, whose default is zero. Put these annotations before their declarations; same-line trailing annotations are also recognized. A grouped declaration shares its annotations across all declared names. Adjacent comments are combined. Names such as @time_step do not bind built-in values. Built-ins must not be arrays or overridden in the document.

Other uniforms are stored by name in uniforms: numeric float or int, boolean, numeric vectors, hexadecimal colors for vec3 or vec4, matrices, or image inputs for sampler2D. ivec2/3/4 use integers; bvec2/3/4 use numeric 0 or 1. mat2/3/4 use 4/9/16 column-major numbers. Numeric arrays use flat numeric lists: vec3 colors[2] requires six numbers. Boolean arrays use numeric 0 or 1. Literal dimensions are checked before browser startup; constant-expression dimensions are compiled by WebGL and their active elements are checked at binding. An optimized unused tail is ignored by the linker. Use complete declared values when the full dimension is known. Grouped declarations such as uniform float first, second[3]; are accepted.

Unset numeric values, vectors, matrices, and active numeric array elements use zero. An unset sampler gets a transparent image. These are WebGL zero defaults; Pencil-specific annotation default syntax still requires verification. Inputs and defaults are prepared for rendering without rewriting the saved shader or document.

Image sampler URLs resolve through captured document assets. An effect can bind pencil:object to the already rendered node. pencil:background captures the scene before that node, including relevant parent layers. Effect order matters: each shader receives the result of previous effects. Fill-stage pencil:object is currently unavailable. Internal texture orientation is handled by the runtime; do not compensate for it by flipping ordinary input images again.

For a variable-valued image URL, lazypencil follows aliases and the active theme, then resolves the image relative to the document defining the selected value. The same variable's text uses keep their original strings. Detachment retains these linked variables and their image origins. Standalone component copying with string-valued image sampler variables remains unsupported; inspect capabilities and use a linked component when appropriate. Pencil parity of this imported-variable path policy is unverified.

Use render time to evaluate animation at a reproducible instant. Request a new time to change it. The result includes the actual browser and software renderer, enabled extensions, request hash, and PNG hash. Captured runtime.shader settings control acquisition/launch deadlines and idle expiry; runtime.dynamic controls the shared render budget and encoded-raster cache. Acquisition metadata reports effective limits, and changing policy invalidates old cached rasters. Compilation, linking, invalid uniforms, missing inputs, context loss, and deadlines are errors. Generated pixels do not replace editable source code in the document.

Current limits include 1 MiB of GLSL, 262,144 declaration tokens, 256 uniform names, 256 array elements, 4,096 supplied/active numeric components, 8,192 pixels per side, and 16 megapixels per dynamic raster. Image sampler arrays, multidimensional arrays, structs, and macro-generated uniform declarations remain unsupported. Constants/macros used only for array dimensions are passed through to WebGL. Common vec2 UV varying aliases are provided, but full Pencil vertex and annotation compatibility has not been established. Inspect both the full design and relevant detail images before reporting success.
