# Dashboards and dense workspaces

Begin with the decisions the dashboard supports. Prioritize a small set of useful summaries and provide the detail that explains them. Give metrics meaningful labels, units, time periods, and comparison context. Use realistic values and avoid decorative numbers that imply unavailable evidence.

Align repeated rows and numeric columns. Keep sorting, filtering, selection, and status cues consistent. Use spacing, dividers, and restrained type hierarchy to organize density. Do not make every metric a separate strongly colored card or shrink all text to fit more content.

The dense-workspace style provides a compact neutral structure with one accent. Adapt it to the actual information rather than filling all sample regions mechanically. If charts are required, provide meaningful scales, labels, and data; use editable geometry or supported assets rather than a misleading placeholder.

Inspect row density and the balance between overview and detail at the intended viewport. Check long names, empty values, large numbers, and state labels. A dense interface should still have a clear reading order and an obvious next action.
