# Dashboards and dense workspaces

Begin with the decisions the dashboard supports. Prioritize useful summaries and the detail that explains them. Give metrics meaningful labels, units, time periods, and comparison context. Use realistic values without implying evidence the user has not supplied.

Align repeated rows and numeric columns. Keep sorting, filtering, selection, and status cues consistent. Use spacing, dividers, and type hierarchy to organize density; emphasis should reflect the information's importance. Read `components` when rows, cards, or controls should share future design changes.

The optional dense-workspace style provides a compact neutral structure with one accent. Adapt it to the information rather than filling sample regions mechanically. For charts, provide meaningful scales, labels, and data using editable geometry or suitable assets.

Inspect density and the balance between overview and detail at the intended size. Check long names, empty values, large numbers, state labels, and the actions needed for the task.
